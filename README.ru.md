# AI Browser

[English](README.md) | **Русский**

![Логотип AI Browser](extension/icons/logo-128.png)

**Дайте AI-агенту доступ к нужным страницам в вашем обычном Chrome.**

AI Browser соединяет Chrome с **Codex и Claude** через MCP: агент может читать страницы, переходить по ссылкам и заполнять формы по вашей просьбе. Вы продолжаете пользоваться своим браузером, профилями и аккаунтами, в которые уже вошли.

Проект состоит из расширения Chrome и небольшой локальной программы. Они общаются с агентом через MCP — стандарт подключения инструментов к AI-клиентам. Ни отдельный браузер, ни Docker, ни открытый порт удалённой отладки не нужны.

Для браузерной части нужны **macOS и Google Chrome**. Ниже приведены инструкции подключения к Codex и Claude.

## Для чего это удобно

- Попросить агента изучить открытую страницу и объяснить её содержимое.
- Заполнить форму, выбрать дату, отметить пункты и прикрепить указанный файл.
- Проверить веб-интерфейс во время разработки.
- Выполнить последовательность действий на сайте, сохраняя возможность видеть результат в Chrome.
- Вести несколько задач в разных группах вкладок.

Например:

> Открой example.com и расскажи, что есть на странице.
>
> Прочитай выбранную вкладку и выдели основные условия.
>
> Заполни форму этими данными. Перед отправкой покажи результат.

## Отличия от инструментов Claude и OpenAI

Главное преимущество AI Browser — **один локальный MCP-сервер для Codex и Claude**. При смене AI-клиента не нужно менять расширение и локальный мост. Исходники расширения и сервера доступны в этом репозитории; способ подключения и правила работы можно настроить под свои задачи.

| Вариант | Когда подходит | Что учитывать |
| --- | --- | --- |
| **AI Browser** | Нужен отдельный MCP-инструмент для Codex или Claude, в том числе для работы из терминала | Ручная установка; браузерная часть рассчитана на macOS и Google Chrome |
| [**Claude in Chrome**](https://code.claude.com/docs/en/chrome) | Нужна готовая интеграция с Claude и Claude Code, разрешениями сайтов и поддержкой Anthropic | Работает в экосистеме Claude и по условиям её доступа |
| [**ChatGPT browser extension**](https://learn.chatgpt.com/docs/chrome-extension) от OpenAI | Нужна готовая интеграция с ChatGPT, боковой панелью и разрешениями сайтов | Доступность зависит от плана и настроек рабочей области ChatGPT |

Официальные расширения тоже используют существующие входы в браузере. У Claude есть собственная MCP-интеграция с Chrome и группы вкладок, поэтому эти возможности не уникальны для AI Browser. Встроенный [Browser OpenAI](https://learn.chatgpt.com/docs/browser) — отдельный вариант с собственным профилем, а не ваш обычный Chrome; в Codex CLI и IDE он недоступен.

Выбирайте AI Browser, если вам нужен самостоятельный инструмент для обоих клиентов. Официальные расширения удобнее, если важнее готовый интерфейс и управление доступом к сайтам без настройки собственного моста. Сравнительных измерений скорости, расхода токенов и безопасности у проекта пока нет.

## Что умеет агент

| Задача | Возможности |
| --- | --- |
| Читать сайт | Текст страницы, ссылки, поля и кнопки; скриншоты для визуальной проверки |
| Перемещаться | Открывать страницы, переходить по ссылкам и выбирать вкладку внутри своей группы |
| Работать с формами | Вводить текст, выбирать пункты, управлять флажками, датами и редактируемыми блоками |
| Загружать файлы | Выбирать существующие локальные файлы для поля загрузки |
| Работать со сложными элементами | Использовать клавиатуру и клик по скриншоту, когда обычного элемента страницы недостаточно |
| Продолжать задачу | Восстанавливать подключение после временного обрыва; обновлять Python-компонент без закрытия вкладок |

Чтение содержимого и выбор элементов внутри iframe другого origin через DOM не поддерживаются, хотя содержимое такого iframe может быть видно на скриншоте страницы. Поддерживаются iframe с тем же origin и элементы Shadow DOM. Особенности отдельных сайтов могут требовать ручного действия.

## Требования

- macOS и установленный Google Chrome.
- Python **3.11 или новее** и Git.
- AI-клиент с поддержкой локальных MCP-серверов: Codex, Claude Code или Claude Desktop. Для примеров с CLI нужна команда `codex` либо `claude`.
- Ваш обычный доступ к AI-модели через выбранный клиент. Самому AI Browser ключи OpenAI или Anthropic не нужны; условия и стоимость AI-клиента действуют отдельно.

## Установка

Команды ниже выполняются в Terminal. Не переносите папку проекта после настройки: Chrome и AI-клиент будут использовать пути внутри неё.

### 1. Скачайте проект и установите программу

```sh
git clone https://github.com/d0grr/ai-browser.git
cd ai-browser
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-mcp.lock
.venv/bin/python -m pip install --no-deps -e '.[mcp]'
```

### 2. Добавьте расширение в Chrome

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `extension` внутри проекта.
4. Скопируйте **ID** расширения AI Browser с его карточки.

### 3. Соедините расширение с локальной программой

Из той же папки проекта выполните команду, заменив `EXTENSION_ID` на скопированный ID:

```sh
.venv/bin/ai-browser install EXTENSION_ID
```

Команда создаёт настройки Native Messaging в пользовательской папке Chrome. Это механизм, через который расширение связывается с локальной программой. Если расширение было загружено до установки, перезагрузите его кнопкой на карточке в `chrome://extensions`.

### 4. Подключите свой AI-клиент

**Codex:**

```sh
codex mcp add ai-browser -- "$PWD/.venv/bin/python" -m ai_browser.mcp_server
codex mcp list
```

**Claude Code:**

```sh
claude mcp add --transport stdio --scope user ai-browser -- "$PWD/.venv/bin/python" -m ai_browser.mcp_server
claude mcp list
```

В обоих примерах регистрация пользовательская: сервер будет доступен и при работе из других папок. В Claude Code список инструментов также доступен через `/mcp`. Подробнее — в [документации Claude Code](https://code.claude.com/docs/en/mcp#option-3-add-a-local-stdio-server).

**Claude Desktop:**

В файле `~/Library/Application Support/Claude/claude_desktop_config.json` добавьте `ai-browser` в существующий объект `mcpServers`, сохранив остальные серверы и настройки. Вместо `/absolute/path/to/ai-browser` укажите полный путь к проекту — его можно узнать командой `pwd` в папке проекта:

```json
{
  "mcpServers": {
    "ai-browser": {
      "command": "/absolute/path/to/ai-browser/.venv/bin/python",
      "args": ["-m", "ai_browser.mcp_server"]
    }
  }
}
```

Это локальный MCP-сервер, а не URL удалённого коннектора. Подробнее — в [инструкции подключения локальных MCP-серверов](https://modelcontextprotocol.io/docs/develop/connect-local-servers).

После изменения настроек перезапустите выбранный клиент и начните новый диалог.

### 5. Попробуйте первый запрос

Откройте нужный профиль и окно Chrome, затем напишите в Codex или Claude:

> Используй ai-browser: открой https://example.com и кратко опиши страницу.

При первом открытии сайта агент создаст группу **AI Browser** или использует свободную группу с таким названием. Если подходящих окон несколько и выбор неоднозначен, укажите нужное окно.

## Как выбираются вкладки

У каждого MCP-подключения своя привязка к профилю, окну и группе **AI Browser**. Одновременно работающие подключения не делят одну группу. После завершения подключения вкладки остаются в Chrome, а освободившуюся группу можно использовать снова.

По умолчанию агент читает **только выбранную вкладку**. Для другой страницы укажите её явно; для всей группы попросите прочитать всю группу. Другие пользовательские группы не подключаются автоматически.

Чтобы дать агенту уже открытую страницу, перенесите её в его группу AI Browser средствами Chrome и попросите выбрать эту вкладку. Если убрать вкладку из группы, новые команды потеряют к ней доступ. Текст, который уже попал в историю диалога, останется в ней.

Обычные действия с элементами страницы работают в фоне. Активность пользователя на той же вкладке не останавливает агента, поэтому одновременное редактирование одной формы может мешать выполнению задачи.

## Выбор AI Browser по умолчанию в Codex

Этот шаг необязателен. Без него можно явно писать «используй ai-browser».

Чтобы Codex выбирал AI Browser для обычных просьб открыть сайт или поработать на странице, подключите навык из корня проекта:

```sh
mkdir -p ~/.agents/skills
ln -s "$PWD/skills/ai-browser" ~/.agents/skills/ai-browser
```

Если навык с таким именем уже установлен, сначала проверьте существующую папку или ссылку.

Добавьте в `~/.codex/AGENTS.md` правило:

```text
Для браузерных действий по умолчанию используй MCP ai-browser и навык
ai-browser. Явный выбор другого инструмента пользователем имеет приоритет.
```

Начните новую сессию Codex. После этого можно писать «открой Chrome», «зайди на example.com» или «прочитай выбранную вкладку» без названия инструмента. Правило направляет действия агента; текстовые запросы само расширение не перехватывает.

## Доступ к данным и разрешения

Расширение запрашивает широкие разрешения для HTTP/HTTPS-страниц, выполнения действий и Chrome debugger. Встроенные проверки AI Browser ограничивают команды группой текущего подключения. Это ограничение программы, а не отдельная изолированная среда браузера.

Соединение между расширением и локальной программой работает на вашем компьютере. При чтении страницы её текст или скриншот попадают в AI-клиент и могут передаваться провайдеру модели по его правилам. «Локальный мост» не означает, что весь AI работает локально.

Значения полей пароля исключены из снимка элементов; обычные инструменты ввода не заполняют пароли. Остальные видимые данные страницы могут попасть в контекст. Для входа используйте Chrome самостоятельно.

Для загрузки агенту нужны конкретные существующие файлы и их абсолютные пути. После выбора файла сайт может сразу начать отправку. Успешный выбор ещё не подтверждает завершение загрузки.

Для системного клика по скриншоту, например по нативному календарю Chrome, нужны разрешения macOS **Универсальный доступ** и **Запись экрана** для приложения, которое запускает MCP. Целевые окно и вкладка должны быть активны и видимы. Обычные действия на странице этих системных разрешений не требуют.

Если соединение оборвалось после клика или ввода и результат неизвестен, агент не должен автоматически повторять действие: сначала нужно проверить страницу. Предупреждение Chrome о несохранённых изменениях агент обрабатывает с учётом задачи; это не гарантия сохранения данных на сайте.

## Обновление

В папке проекта:

```sh
git pull --ff-only
.venv/bin/python -m pip install -r requirements-mcp.lock
.venv/bin/python -m pip install --no-deps -e '.[mcp]'
```

Перезагрузите расширение в `chrome://extensions`. Для обновления Python-компонента попросите агента выполнить `browser_restart`; открытые вкладки сохранятся. Если после обновления отсутствуют новые инструменты, переподключите MCP-сервер или перезапустите свой AI-клиент.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Клиент не видит AI Browser | Запустите `codex mcp list` или `claude mcp list`, проверьте путь к Python и перезапустите клиент |
| Расширение не соединяется | Проверьте ID в команде установки, перезагрузите расширение и посмотрите сообщение в его всплывающем окне |
| Агент не видит открытую страницу | Убедитесь, что страница находится в группе этого подключения, и явно укажите вкладку |
| Не удаётся выбрать окно или профиль | Попросите агента показать доступные подключения и окна, затем укажите нужные |
| Не работает системный клик | Проверьте разрешения macOS, активность целевой вкладки и отсутствие перекрывающих окон |
| Chrome показывает полосу отладки | Она связана с разрешением debugger, которое используется для ввода и наблюдения за диалогами |

Всплывающее окно расширения показывает состояние соединения. Для диагностики MCP-подключения попросите агента вызвать `browser_status`; список профилей доступен через `browser_connections`.

## Для разработчиков

Тесты требуют установленного MCP-окружения и Node.js:

```sh
BROWSER_BRIDGE_TEST=1 .venv/bin/python -m unittest discover -s tests -v
node --test tests/*.test.cjs
```

Подробности инструментов, восстановления подключения и ограничений находятся в [техническом справочнике](docs/technical-reference.ru.md). Правила работы агента — в [навыке AI Browser](skills/ai-browser/SKILL.md).
